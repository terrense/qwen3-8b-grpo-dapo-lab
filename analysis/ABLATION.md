# 四臂消融 + 一个把前面所有结论重新定性的发现

**最重要的一条先说：同一个算法跑两次，reward 会符号翻转、长度会差 65%。
所以四个臂在 reward / 长度 / validation 上的任何差异都在单算法自身的运行间方差以内，
不能用来区分算法。但机制类指标复现到 5% 以内，那些结论是站得住的。**

---

## 一、运行间方差：同一算法两次运行

我有两次 **vanilla GRPO** 的独立 20-update 运行，配置完全相同，
只差训练 prompt 池（`M20_grpo` 用 dedup[200:]，`A_grpo` 用 dedup[1500:]，
因为中间把验证集从 200 加到了 1500）。

| 指标 | M20_grpo | A_grpo | 差异 |
|---|---|---|---|
| **reward 后5均值** | **+0.159** | **−0.097** | **符号翻转** |
| **回答长度 末** | **1430** | **2353** | **+64.6%** |
| clipfrac 均 | 1.74e-4 | 1.22e-4 | −30.1% |
| entropy 末 | 0.299 | 0.327 | +9.6% |
| grad_norm 均 | 0.253 | 0.239 | −5.3% |
| **ratio \|ρ−1\| p99 均** | **0.0558** | **0.0552** | **−1.0%** |
| **advantage max 均** | **2.389** | **2.326** | **−2.7%** |

**清晰的两类：**

- **结果类指标**（reward、回答长度）：差 65%~160%，reward 甚至符号都翻了
- **机制类指标**（ratio 分布、advantage 尺度、grad_norm）：**复现到 1%~5%**

这不奇怪 —— 每个 update 只有 16 道题，题目难度的批间方差极大；20 个 update 总共才见过
320 道题。而 ratio 分布和 advantage 尺度是由算法本身的数学决定的，跟抽到哪些题关系不大。

**直接后果：n=1 的 20-update 运行，可以用来验证机制，不能用来比较效果。**

## 二、四臂结果

配置对齐：Qwen3-8B、seed 20260910、`train_batch_size=16`、`rollout.n=8`、
`ppo_mini_batch_size=8`、`max_response_length=8192`、关 thinking、`lr=1e-6`、
**验证集 1500 题**（标准误 1.29 个百分点）。

| 臂 | policy loss | loss 聚合 | 其他 |
|---|---|---|---|
| **A_grpo** | vanilla | token-mean | 对照 |
| **B_gspo** | gspo | seq-mean-token-mean | |
| **C_aggonly** | vanilla | seq-mean-token-mean | 分离变量的关键臂 |
| **D_drgrpo** | vanilla | seq-mean-token-sum-norm | `norm_adv_by_std=False`, `loss_scale_factor=8192` |

| | A_grpo | B_gspo | C_aggonly | D_drgrpo |
|---|---|---|---|---|
| val @10 | 44.87% | 45.53% | 44.53% | 46.47% |
| **val @20** | **46.93%** | **46.53%** | **48.47%** | **47.67%** |
| 相对 A 的差 | — | −0.40pp | +1.53pp | +0.73pp |
| **= 几个标准误** | — | 0.22 | **0.84** | 0.40 |
| reward 后5 | −0.097 | −0.088 | −0.084 | −0.066 |
| **clipfrac 均** | 1.22e-4 | **0** | 1.37e-4 | 1.54e-4 |
| **advantage max 均** | 2.326 | 2.134 | 2.475 | **1.675** |
| ratio \|ρ−1\| p99 | 0.0552 | **4.71e-4** | 0.0552 | 0.0556 |
| 回答长度 末 | 2353 | 2415 | 2520 | 2363 |

### validation：即使 1500 题也分辨不出

最大差异是 C 比 A 高 **1.53 个百分点 = 0.84 个标准误**。**不显著。**

而且上一节测出来，同一算法两次运行的 reward 都能翻符号 —— 这 1.53 个百分点
完全在运行间方差以内。

**把验证集从 200 加到 1500 解决了测量精度问题，但没解决真正的瓶颈：
20 个 update 太短，n=1 太少。** 现在的限制因素是运行数，不是验证集大小。

## 三、B − C：sequence-level clipping 的净贡献 ≈ 0（而且方向是负的）

这是设计 `C_aggonly` 的目的。GSPO 同时改了两件事，C 只改其中一件：

```
B_gspo    = sequence ratio + clipping  +  seq-mean-token-mean 聚合
C_aggonly =                               seq-mean-token-mean 聚合
```

| | val@20 | clipfrac |
|---|---|---|
| B_gspo（完整 GSPO） | 46.53% | **0** |
| C_aggonly（只换聚合） | **48.47%** | 1.37e-4 |

**C 比 B 还高 1.94 个百分点。** 也就是说加上 sequence-level clipping 之后反而没变好。

结合 **B 的 clipfrac 恰好为 0**（连续两次实验、共 23 个 update 全为 0），
结论是：**在这个配置下 GSPO 的 sequence-level clipping 完全没有生效，
它是一个 inert 的机制**。GSPO 相对 GRPO 的任何差异都只能来自
`seq-mean-token-mean` 这个聚合方式。

（同样的，这 1.94 个百分点本身也在噪声以内，所以严格讲只能说
"没有证据表明 sequence clipping 有正面贡献"。）

## 四、Dr.GRPO 的 advantage 尺度：机制精确确认

`D_drgrpo` 的 `advantage max` 均值是 **1.675**，其他三臂是 2.13~2.48。

这不是噪声，是算术。Dr.GRPO 关掉 std 归一化，所以 advantage = r − mean，不再除以 std：

| k 个答对（共 8） | 不除 std（Dr.GRPO） | 除 std（GRPO） |
|---|---|---|
| 1 | **1.750** | 2.475 |
| 2 | **1.500** | 1.620 |
| 3 | **1.250** | 1.208 |

实测 1.675 落在 k=1 和 k=2 之间（20 步里混合了不同的 k），
对照的 2.326 落在 k=1 的 2.475 附近。**完全吻合。**

这是四个臂里唯一一个**明确超出运行间方差**的差异（1.675 vs 2.326 = 28%，
而同算法运行间 advantage 只差 2.7%）。机制确认。

## 五、一个把 D 臂废掉的混杂：`loss_scale_factor` 悄悄改了有效学习率

D 臂的 `entropy` 末值是 **0.106**，其他三臂是 0.31~0.33。
第一眼像是 entropy 崩塌 —— 但 **D 在 step 1 的 entropy 就是 0.072**，
而三个臂从同一个模型出发，第一步不可能真差 5 倍。

查出来是两件事叠在一起：

**（1）entropy 的"崩塌"是指标假象。** `actor/entropy` 也用 `loss_agg_mode` 聚合。
`seq-mean-token-sum-norm` 除的是常数 `loss_scale_factor=8192`，
而不是实际长度 \|y\|≈1900。验证：

| | 实测 D/A 比值 | 预测 \|y\|/8192 | 平均相对误差 |
|---|---|---|---|
| entropy | 0.2375 | 0.2328 | **3.6%** |

底层 entropy 根本没变，只是被换了个归一化。

**（2）但 grad_norm 小 4.3 倍是真的。** loss 本身被缩放了 \|y\|/8192 ≈ 0.23，
所以 **D_drgrpo 实际上是"有效学习率只有对照 1/4.3 的 Dr.GRPO"**。

这是我照搬 verl 文档"`loss_scale_factor` 设成 max_response_length"造成的。
文档没错，但在做 **matched comparison** 时这个选择会悄悄改掉有效学习率。

**修正**：把 `loss_scale_factor` 设成实际平均长度（~1900）而不是上限（8192），
这样平均意义上和 `token-mean` 的尺度一致。已启动 `E_drgrpo_scaled` 重跑。

## 六、配对长度分析：两次运行给出相反结论

用同一道题内部配对（控制难度）检验 Dr.GRPO 的长度偏差论断：

| 运行 | 错/对比值 首→末 | 同题内错更长的占比 |
|---|---|---|
| M20_grpo | 1.088 → 1.113 | **0.519**（≈抛硬币） |
| **A_grpo** | **1.152 → 1.272** | **0.620**（明显 >0.5） |

**同一个算法，两次运行，一次说"没有效应"，一次说"有明显效应"。**

结合第一节测出的运行间方差（长度末值差 65%），结论只能是：
**20 个 update 下长度类指标不可复现，任何关于长度偏差的结论都需要多 seed 和更长的运行。**

## 七、E_drgrpo_scaled：混杂修掉之后的 Dr.GRPO

把 `loss_scale_factor` 从 8192（max_response_length）改成 1900（实际平均长度）重跑。

| | A_grpo（对照） | D（scale=8192） | **E（scale=1900）** |
|---|---|---|---|
| **step1 grad_norm** | 0.2020 | 0.0421（**0.21×**） | **0.1633（0.81×）** |
| **step1 entropy** | 0.3428 | 0.0719（**0.21×**） | **0.3272（0.95×）** |
| entropy 末 | 0.3272 | 0.1057 | **0.3244** |
| **advantage max 均** | 2.326 | **1.675** | **1.675** |
| grad_norm 均 | 0.2395 | 0.0457 | 0.1685（0.70×） |
| val @20 | 46.93% | 47.67% | 44.93% |
| reward 后5 | −0.097 | −0.066 | −0.181 |

### 三条确认

**1. entropy「崩塌」确实是归一化假象。** E 的 entropy 末值 **0.3244**，
和对照的 0.3272 几乎一样。D 那个 0.106 完全是 `loss_scale_factor` 造成的显示差异，
底层 entropy 从来没变过。

**2. advantage 尺度和 loss 聚合方式完全无关。** D 和 E 的 `advantage max` 都是
**1.675，一模一样** —— 两个臂 `loss_scale_factor` 差 4.3 倍，但 advantage 计算
（`compute_grpo_outcome_advantage`）根本不经过 loss 聚合那一步。这是个干净的正交性验证。

**3. 但有效学习率仍然没完全对齐**：E 的 grad_norm 是对照的 0.70×，不是 1.0×。
因为 `seq-mean-token-sum-norm` 用的是**常数**除数，而实际长度在 1700~2100 之间游走，
比值自然跟着变。

### 一个机械事实（本次未被检验）

`seq-mean-token-sum-norm` 的 loss 是 $rac{1}{C}\sum_t \ell_{i,t}$，
**loss 随 \|y\| 线性增长**；而 `token-mean` 的除数跟着 \|y\| 走，所以有效学习率是稳的。

**推论是：Dr.GRPO 把长度偏差换成了「有效学习率随回答长度漂移」。**

但**这次运行没能检验这个推论** —— E 的回答长度只涨了 3.4%（1828→1890），
而对照涨了 18.7%（1778→2110）。长度没怎么漂，自然测不出漂移效应。
要测需要一个长度明显增长的运行。**记录为机械推论，不作为实测结论。**

### val@20 不做解读

E 是 44.93%，比对照低 2.00pp = 1.10 个标准误。**不显著，而且不可解读** ——
本文档第一节已经测出，同一个算法两次运行 reward 都能符号翻转。
n=1 的情况下这 2 个百分点没有任何信息量。

## 能下 / 不能下的结论

### 能下（机制类，复现性好）

1. **GSPO 的 sequence ratio 把离散度压了约 √\|y\| ≈ 40 倍**，符合中心极限；
   但它的 **clipping 从未触发**（23 个 update 的 clipfrac 全为 0），是 inert 机制
2. **GSPO 的效果只能来自 loss 聚合方式** —— B−C 对比显示加上 sequence clipping 没有正面贡献
3. **Dr.GRPO 的 advantage 尺度精确等于去掉 std 归一化的理论值**（1.675 vs 理论 1.75/1.50）
4. **`loss_scale_factor` 会同时改变 metric 的归一化和有效学习率** —— 做 matched
   comparison 时必须按实际长度设，不能照搬 max_response_length
5. **DAPO 的 dynamic sampling 让 batch 100% 有效**，代价 rollout 时间 1.93 倍，
   单位算力产出反而略低（见 [`ALGORITHM_COMPARISON.md`](ALGORITHM_COMPARISON.md)）

### 不能下（结果类，被运行间方差淹没）

1. **任何"哪个算法效果更好"的结论。** 四臂 validation 差异最大 0.84 个标准误，
   而同算法两次运行的 reward 能翻符号
2. **任何关于长度偏差的结论。** 两次同算法运行给出相反结果
3. **D_drgrpo 这一臂的结果**（有效学习率被缩小 4.3 倍，混杂未解除）

### 下一步真正需要的

不是加更多算法臂，而是：

1. **每个臂跑 3+ 个 seed** —— 现在 n=1，运行间方差比算法间差异大一个量级
2. **更长的运行**（100+ updates）—— 20 步只见过 320 道题
3. 上面两条不做的话，再加多少算法臂都只是在测噪声
